# HSdeck The Boomsday Project 카드 API

`cards.json`과 `render.json`은 기존 HS Plus 카드 정보를 기반으로 하며, `art/`는 설치된 클라이언트의 원화입니다. `golden/`은 해당 카드의 원본 황금 원화 재질·애니메이션·텍스처입니다. 날짜별 과거 원화나 황금 효과를 보장하지 않습니다.


## README: API 경량화·편집 지침 (2026-11-14)

- 공개 필수 파일: `cards.json` 현재 목록과 `data/<CARD_ID>.json` 최초·날짜별 카드 스펙, `art/`·`golden/` 일반/황금 원화·애니메이션, `frame/` 프레임·텍스처·셰이더. `data/history.json` 중앙 원본이 사용 중이면 **별도로 보존**합니다.
- 루트 `render.json`, `history.json` 및 `*-date.json`은 중복 검증/호환 출력이므로 다시 커밋·게시하지 않습니다. 빌드가 생성할 수 있지만 CI 임시 작업물로만 둡니다.
- 카드별 최초 한국 대전 사용 가능일, 모험 지구 실제 개방, 이벤트 실제 시작, 토큰 생성 조건을 검증합니다. 베타의 북미 시간은 KST로 변환하고, 클라이언트 사전 추가일을 사용일로 적지 않습니다. 오기입한 이전 날짜 키는 삭제·통합합니다.
- 능력치·효과·문구는 최초 기록과 후속 변경 필드를 분리합니다. 표시 줄바꿈 `<br></br>`를 적용하며 원시 XML, 원화·황금 애니메이션·프레임 바이너리를 변형하지 않습니다. schema/호환 래퍼의 신규 추가를 금지합니다.
- 원본 XML 증거 `sources/`, 날짜 검증 `tests/`, `tools/`, `.github/`는 재현 가능한 빌드에 필요하므로 참조를 확인하기 전에 삭제하지 않습니다.


## 날짜형 단일 API 정본 (2026-11-14)

`data/<CARD_ID>.json`은 한국 날짜(`YYYY-MM-DD`) 키와 해당 시점의 카드 상태·필드 변화만 표시합니다. 기존 `_meta`, `_current`, 출처 태그 및 감사 내역은 카드 문서에서 제외하되 [원본 검증 보관 브랜치](https://github.com/qxwd565/The-Boomsday-Project/tree/archive/pre-dates-v1-20261114)에 모두 남깁니다. 구형 빌더/회귀 도구는 별도 연구용으로만 유지하며 공개 API 생성에는 사용하지 않습니다. 카드 원화·황금 애니메이션·프레임 바이너리는 변경하지 않습니다.
